# 常见问题

| 现象 | 核对与处理 |
|---|---|
| 后端文件不存在／校验失败 | 对照本版本安装说明核对来源与 SHA-256；版本字符串相同也可能是不同构建。不要关闭校验 |
| 无法连接 | 核对受信任本地工作区、后端位置、账号登录及网络；没有明确成功回执时不要连续发送 |
| 模型不可用 | 刷新后端可见模型，主动选择账号可用项；目录存在也不保证账号有实际调用权限 |
| 发送结果未知 | 查看历史及保留的原提交；确认结果后再恢复或重发，保护后来输入的新稿 |
| 文档读取失败 | 核对格式、加密、大小、文字预算和超时；扫描件需另附图片，当前没有 OCR |
| PDF／Office 预览失败 | 核对 VS Code 查看器或系统默认程序；解析发送与外部预览是不同环节 |
| 额度仍显示旧数据 | 看更新时间和错误提示，手动刷新；失败会保留缓存并退避，断连后不继续刷新 |
| MCP 路径拒绝 | 只使用当前工作区相对路径；隐藏目录、链接和二进制等不支持 |
| Apps 显示已关闭 | 这是本版主动限制，目录读取不启用应用调用 |
| 听写不可用 | 检查 PowerShell 7、系统识别组件、语言包和麦克风权限 |
| 安装后仍像旧版 | 运行“Codex: 显示加载信息”确认实际加载版本；安装与当前窗口加载不是同一状态 |

反馈时提供：插件／VS Code／系统版本、最短复现步骤、预期与实际表现，以及脱敏后的错误信息。不要提供 auth.json、访问令牌、完整账号数据或真实敏感对话。截图也应检查文件路径、附件名和账号信息。
